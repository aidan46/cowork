# Security Policy

## Supported Versions

Only latest `0.6.x` release line gets security fixes.

| Version | Supported |
| --- | --- |
| `0.6.x` | yes |
| `< 0.6.0` | no |

## Report A Vulnerability

Use GitHub private vulnerability reporting:

<https://github.com/aidan46/cowork/security/advisories/new>

Do not open public issues, pull requests, or commits for security problems.

Include when possible:

- affected version or commit
- exact command or workflow
- minimal repro inputs
- model, provider, and host details when relevant
- impact and suspected fix area
- logs or screenshots with secrets removed

Follow-up stays in private advisory thread.
